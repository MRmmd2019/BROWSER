# 🎬 How to sign up for the Model Program

این فایل رسانه‌ای توسط **دانلودر جهانی** مبتنی بر yt‑dlp دریافت شده است.

## 📥 روش استفاده
1. تمام بخش‌های فایل را دانلود کنید (اگر چند بخش است).
2. فایل `.zip` اصلی را با نرم‌افزارهایی مانند WinRAR یا 7‑Zip باز کنید.
3. محتوا را استخراج نمایید.
4. (اختیاری) چکسام SHA256 ارائه‌شده را بررسی کنید.
